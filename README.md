# 💧 HYDRO STRATEGY: OASIS PROTOCOL (Suv Risolasi)

**"Oasis Protocol"** — Qurg'oqchil hududda suv resurslarini oqilona boshqarish, an'anaviy isrofgarchilikdan to'liq avtomatlashtirilgan aqlli sug'orishga o'tish va cho'lni yam-yashil oazisga aylantirish bo'yicha 3D Izometrik Iqtisodiy-Ekologik Strategiya simulyatori.

---

## 🎮 Asosiy Xususiyatlar

* **3D Izometrik Low-poly Olam (Three.js)**:
  * Dinamik tuproq relefi, o'simliklar o'sish fazalari va real vaqtli suv animatsiyalari.
  * To'liq interaktiv kamera: Pan (`W, A, S, D`), Orbit Rotate (O'ng tugma / g'ildirak), Zoom (G'ildirak).
* **4 Bosqichli Sug'orish Texnologiyalari Daraxti (Tech Tree)**:
  1. *Egatlab / Bostirib sug'orish* (Arzon, 55% isrof, sho'rlanish xavfi).
  2. *Yomg'irlatib va Er usti tomchilatish* (30-45% suvni tejash).
  3. *Yer ostidan tomchilatish — SDI* (Bug'lanish deyarli 0%, 70%+ tejamkorlik).
  4. *Smart SCADA + IoT + AI (Fuzzy-PID)* (Zero-waste avtomatik dozalash).
* **5 Xil Ko'rgazmali Qatlam (Heatmaps)**:
  * 🌐 Tabiiy 3D
  * 💧 Namlik Xaritasi ($VWC\%$)
  * 🔥 Suv Yo'qotish / Bug'lanish Xaritasi
  * 🧂 Tuproq Sho'rlanishi Xaritasi
  * 📡 IoT Qamrovi & SCADA Tarmog'i
* **Smart SCADA & Telemetriya Markazi**:
  * Haqiqiy vaqtli $VWC\%$ vs $Setpoint$ dinamik grafiklari.
  * AI Avto-Dozalash va ob-havo prognoziga moslashish ($ET_0$).
* **Dinamik Inqirozlar (Crisis Events)**:
  * Issiqlik to'lqini (Heatwave), Qurg'oqchilik (Drought), Quvur yorilishi (Pipe burst), Sho'rlanish (Salinity bloom).
* **O'yinni Qayta Boshlash (Restart Engine)**:
  * Istalgan vaqtda o'yinni yangitdan boshlash uchun qulay boshqaruv va tasdiqlash modali.
* **Protsedurali Ovoz Tizimi**:
  * Web Audio API orqali sintez qilingan effektlar va sokin oazis shabbodasi.

## 🚀 Ishga Tushirish (Quick Start)

### Talablar:
* [Node.js](https://nodejs.org/) (v18 yoki undan yuqori)

### O'rnatish va Ishga tushirish:
```bash
# Bog'liqliklarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish (Dev server)
npm run dev

# Ishlab chiqarish (Production) uchun yig'ish
npm run build
```

Brauzerda `http://localhost:3000` manzilini oching.
